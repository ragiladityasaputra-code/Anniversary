# Website Anniversary

## Cara pakai
1. Buka folder ini di VS Code (File > Open Folder).
2. Edit nama, tanggal jadian, surat, dan alasan di `config.js`.
3. Taruh foto/video di folder `foto/`, lalu daftarkan namanya di `photos` dalam `config.js`.
4. Buka `index.html` di browser (atau pakai ekstensi Live Server di VS Code biar otomatis refresh).

## Struktur
- `index.html`: isi halaman
- `style.css`: tampilan dan warna (warna ada di bagian `:root` paling atas)
- `config.js`: teks, tanggal, dan daftar foto
- `script.js`: animasi dan tombol interaksi
- `foto/`: foto dan video

## Biar bisa dibuka Annisa
Unggah seluruh folder ke hosting statis gratis, misalnya Netlify (tarik folder ke netlify.com/drop) atau GitHub Pages, lalu kirim linknya.
